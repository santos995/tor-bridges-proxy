# Tor Bridges
# Add your bridges here, one per line
#
# Supported bridge types:
#
# OBFS4 (most common):
#   Bridge obfs4 <fingerprint> <ip>:<port> <cert> <iat-mode>
#   Example: Bridge obfs4 AAAA... 192.0.2.1:443 cert=abcd... iat=strobe
#
# SNOWFLAKE (WebRTC-based, works through most firewalls):
#   Bridge snowflake <proxy-domain>
#   Example: Bridge snowflake https://snowflake.torproject.org
#
# MEEK (Azure/AWS fronting):
#   Bridge meek_lite <domain> [endpoint-domain]
#   Example: Bridge meek_lite 0.0.0.0:0 https://fastmail.com
#
# WEBTUNNEL (requires separate binary not in Alpine repo):
#   Bridge webtunnel <domain> <server-key>
#
# DNSTT (DNS tunneling, requires separate binary not in Alpine repo):
#   Bridge dnstt <subdomain>
#
# Notes:
# - Lines starting with # are treated as comments and ignored
# - Empty lines are ignored
# - Obfs4, snowflake, and meek are built-in to Alpine packages
# - Webtunnel and dnstt are NOT available in Alpine — see README for manual installation
