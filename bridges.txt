# Tor Bridges
# Add your bridges here, one per line
#
# Supported bridge types (all are auto-detected):
#
# ─── OBFS4 (most common, prebuilt in Alpine) ───
# Bridge obfs4 <fingerprint> <ip>:<port> <cert> <iat-mode>
# Example:
# Bridge obfs4 AAAA... 192.0.2.1:443 cert=abcd1234... iat=strobe

# ─── SNOWFLAKE (WebRTC, good for heavy censorship) ───
# Bridge snowflake <proxy-domain>
# Example:
# Bridge snowflake https://torproject.org

# ─── MEEK (domain fronting via CDNs) ───
# Bridge meek_lite <domain> [endpoint-domain]
# Example:
# Bridge meek_lite 0.0.0.0:0 https://fastmail.com

# ─── WEBTUNNEL (requires manual install, see README) ───
# Bridge webtunnel <domain> <server-key>
# Example:
# Bridge webtunnel example.com AAAAAAAAAAAAAA

# ─── DNSTT (DNS tunneling, requires manual install, see README) ───
# Bridge dnstt <subdomain>
# Example:
# Bridge dnstt test

# Notes:
# - Lines starting with # are comments (skipped)
# - Empty lines are ignored
# - obfs4, snowflake, and meek are prebuilt and ready to use
# - webtunnel and dnstt are NOT prebuilt — see README for instructions
